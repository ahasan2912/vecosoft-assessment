--- Prompt 1: Planning --- 
Act as a Principal Frontend Engineer and Senior UI/UX Designer. Build a modern, professional, responsive mobile Order Tracking application for an e-commerce platform based on the following task requirements.

### Project Stack & Requirements
1. Tech Stack: React (or Next.js), Tailwind CSS, Lucide Icons, and React State management.
2. Target Screen: Mobile viewports (responsive between 360px and 430px width).
3. Data Source: Mock/Static JSON data with state switching capability. No backend required.

### Core UI & UX Requirements
- Visual Delivery Progress Timeline: Clear step-by-step visual tracker (e.g., Order Placed -> Processing -> Shipped -> Out for Delivery -> Delivered) with status badges and timestamps.
- Current Order Status: Clear header banner reflecting current status.
- Estimated Delivery Information: Estimated date, time window, or contextual delivery notes.
- Product & Order Summary: Expandable/collapsible item details, image thumbnail, quantity, price, order ID, and payment summary.
- Customer Support & Actions: Quick action buttons to "Contact Support", "Call Courier", or "Report an Issue".
- State Switcher (Demo Controls): Provide a subtle top bar or floating toggle to instantly switch between the normal view and the 3 required edge-case scenarios below.

### 3 Mandatory Edge-Case Scenarios to Handle

1. Delayed Order Scenario:
   - Condition: Estimated delivery time has passed or order is significantly delayed.
   - UI Response: Display a prominent notice/warning banner, explain the reason (e.g., severe weather or high volume), update estimated arrival date, and provide actionable next steps (e.g., "Request Update" button or "Chat with Support").

2. Delivered but Not Received Scenario:
   - Condition: Status shows "Delivered", but user clicks a flag or toggles "I didn't receive this".
   - UI Response: Display an urgent resolution panel showing delivery details (photo proof placeholder, drop-off location note) and provide immediate recovery options (e.g., "Check Security/Neighbours", "Report Missing Package", "Instant Refund/Support Ticket").

3. Tracking Not Available Yet Scenario:
   - Condition: Order placed recently, fulfillment in progress, tracking number not yet assigned by carrier.
   - UI Response: Avoid empty or broken screens. Show an engaging preparation state (e.g., "Preparing your order", estimated time until dispatch, carrier assignment pending animation, and option to get SMS/Email alerts).

### Design & Micro-Interactions
- Clean typography, smooth transitions, proper visual hierarchy, and professional spacing.
- Interactive elements: Interactive tabs/buttons, modal or bottom sheet for contacting support, and interactive issue reporting flow.
- Micro-states: Proper handling of visual active/completed/pending states in the timeline.

### Output Needed
1. Complete, clean, and modular React component structure.
2. Fully stylized with Tailwind CSS.
3. Everything self-contained and ready to run locally.
